모아+ 2.1.1 — 진동 반응이 빨라졌습니다.

[개선]
- 키를 뗄 때가 아니라 **누르는 순간** 진동이 옵니다. 모아+ 는 긋기 키보드라 손가락이 붙어 있는 시간이 길어서, 획을 다 긋고 뗄 때 울리면 반응이 늦게 느껴졌습니다. 이제 iOS 기본 키보드처럼 누르자마자 반응합니다. (GitHub 이슈 #23 제보 반영)

[2.1 에서 들어온 단축어 개편]
- 마침표나 물음표 같은 기호가 들어간 단축어를 쓸 수 있습니다. 앞에 붙여도(.ㄱㅅ), 뒤에 붙여도(ㅏ..) 동작합니다.
- 문장에 바로 이어 붙여 써도 인식됩니다. '안녕.ㄱㅅ' 처럼 앞말과 띄어쓰지 않아도 됩니다.
- 단축어를 확정한 띄어쓰기를 결과 뒤에 남기지 않도록 설정할 수 있습니다.
- 변환 직후 지우기를 누르면 원래 글자로 되돌아가는 동작을 설정에서 끄거나 켤 수 있습니다.
- 너무 짧은 단축어는 의도하지 않게 변환되기 쉬워 새로 등록할 때 기본적으로 막아 둡니다. 원하시면 설정에서 제한을 풀 수 있고, 이미 등록해 두신 단축어는 그대로 동작합니다.
- 단축어 후보가 뜰 때 키보드 아래쪽이 잘리던 문제, 키보드를 열어 둔 채 다른 앱에 다녀오면 입력이 되지 않던 문제를 고쳤습니다.

[2.0 에서 들어온 입력 방식 개편]
순정 모아키의 실제 입력을 프레임 단위로 실측해 입력 방식을 그대로 맞춘 업데이트였습니다.
- 대각선 왕복으로 ㅐ·ㅔ·ㅢ: ↗로 나갔다 ↙로 되돌아오면 ㅐ, ↖↘는 ㅔ, ↙↗는 ㅢ.
- ㅚ에서 이어 긋는 세로 체인: 위·아래로 긋고 →면 ㅘ, →←면 ㅙ, ←면 ㅕ. 고→괴→과→괘처럼 떼지 않고 이어집니다.
- ㆍ 조합 확장: 외+ㆍ=와, 위+ㆍ=워, 애+ㆍ=얘, 오↔요 토글.
- 한 자소씩 지우기: 백스페이스가 받침 → 모음 → 자음 순서로 지웁니다.

기본 입력은 전체 접근 권한 없이 동작합니다. 햅틱 진동을 쓰려면 iOS 제약상 전체 접근 허용이 필요하지만(선택), 켜더라도 입력하신 내용은 외부로 전송되지 않습니다.
