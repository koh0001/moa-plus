# 단축어 개편 실기기 확인 체크리스트

대상: `feat/abbreviation-symbol-trigger` (기호 트리거 지원 + 확정 스페이스/되돌리기 설정)
시뮬레이터 유닛 테스트는 전부 통과. **여기서 보는 것은 유닛 테스트가 못 보는 것 하나다 —
호스트 앱이 돌려주는 `documentContextBeforeInput` 에 의존하는 삭제 산술.**

---

## 0. 사전 준비

- [ ] 앱 삭제 후 재설치 대신 **기존 설치 위에 덮어쓰기**로 빌드 (기존 설정 마이그레이션 확인)
- [ ] 설정 → 단축어에서 아래 6개 등록

| 트리거 | 치환 문구 | 확정 방식 | 용도 |
|--------|-----------|-----------|------|
| `ㅎㅌ` | `♥` | 자동 확정 | 기존 동작 회귀 |
| `.ㅎㅌ` | `♥♥` | 자동 확정 | 기호 접두 (제보 핵심) |
| `ㅏ..` | `Aㅏ....` | 자동 확정 | 기호 접미 |
| `ㄱㅅ` | `감사합니다` | 자동 확정 | 기호로 확정하는 경로 |
| `ㅈㅅ` | `죄송합니다` | **후보 선택** | 후보 바 경로 |
| `ㄴㅇ` | `내용이 아주 긴 문장을 여기에 넣어 둡니다` | 자동 확정 | 긴 치환 |

- [ ] 설정값 초기 상태 확인: 단축어 사용 **ON** / 변환 후 띄어쓰기 유지 **ON** /
      백스페이스로 되돌리기 **ON** / 트리거 제한 **안전**

> ⚠️ 아래에서 **한 글자라도 엉뚱하게 지워지면** 그 자리에서 멈추고 §7 양식으로 기록할 것.
> 앞 글자를 먹는 버그가 이번 변경의 최대 위험이다.

---

## 1. 호스트별 반복 (가장 중요)

아래 5개 호스트에서 **§2 핵심 5종**을 각각 돌린다. 호스트마다 컨텍스트 API 동작이 달라서,
한 곳에서 되고 다른 곳에서 깨지는 것이 이 기능의 전형적 실패 방식이다.

- [x] **iOS 메모** (UITextView)
- [x] **카카오톡 대화 입력창** — 전송 후 재입력까지 확인
- [ ] **모아+ 앱 → 타이핑 연습** (SwiftUI TextField) — v1.7.2 커서 탭 버그가 났던 호스트
- [x] **사파리 주소창** (자동완성이 강하게 개입)
- [x] **비밀번호 입력칸** (보안 필드, 컨텍스트 `nil`) — 확장이 되든 안 되든
      **텍스트가 깨지지만 않으면 통과**

---

## 2. 핵심 5종 (호스트마다 반복)

### 2-1. 기존 동작 회귀
- [ ] 빈 칸에서 `ㅎㅌ` + 스페이스 → `♥ `
- [ ] `ㄱㅅ` + 스페이스 → `감사합니다 `

### 2-2. 기호 접두 트리거 (제보 1·2)
- [ ] 빈 칸에서 `.` `ㅎ` `ㅌ` + 스페이스 → `♥♥ `

### 2-3. ⚠️ 앞말에 붙여 쓰기 — **삭제 산술 최대 위험**
- [ ] `안녕` 입력 후 이어서 `.` `ㅎ` `ㅌ` + 스페이스
      → **`안녕♥♥ `** (`안녕` 이 그대로 남아야 함)
- [ ] `안녕하세요` 입력 후 이어서 `.` `ㅎ` `ㅌ` + 스페이스 → `안녕하세요♥♥ `
- [ ] 문장 중간에서: `오늘 날씨가` + 스페이스 + `.ㅎㅌ` + 스페이스 → `오늘 날씨가 ♥♥ `

### 2-4. 기호로 확정
- [x] `ㄱㅅ` + `.` → `감사합니다.` (마침표 1개, 2개 아님)
- [x] `.ㅎㅌ` + `.` → `♥♥.`
- [x] `ㅏ` `.` `.` + 스페이스 → `Aㅏ.... `
- [x] `ㅏ` `.` `.` `.` (마침표 3개) → `Aㅏ.....`
      *세 번째 마침표가 확정 신호로 동작하는 것이 의도된 동작*

### 2-5. 오발동 없어야 함
- [x] `안녕ㅎㅌ` + 스페이스 → **변환 없음**, `안녕ㅎㅌ ` 그대로
      *(기호 없는 트리거는 어절 중간에서 발동하지 않아야 함)*
- [ ] `ㅎ` + 스페이스 → 변환 없음
- [ ] 등록하지 않은 `ㅋㅋ` + 스페이스 → 변환 없음

---

## 3. 되돌리기 / 띄어쓰기 설정

### 3-1. 되돌리기 ON (기본)
- [ ] `ㅎㅌ` + 스페이스 → `♥ ` → 백스페이스 1회 → **`ㅎㅌ`**
- [ ] 이어서 백스페이스 → `ㅎ` → 백스페이스 → 빈 칸
- [ ] `안녕` + `.ㅎㅌ` + 스페이스 → 백스페이스 1회 → **`안녕.ㅎㅌ`** (`안녕` 보존)
- [ ] 되돌린 뒤 스페이스 다시 → 재확장 `♥ `

### 3-2. 되돌리기 OFF
- [ ] 설정에서 "백스페이스로 되돌리기" **끄기**
- [ ] `ㅎㅌ` + 스페이스 → `♥ ` → 백스페이스 → **`♥`** (트리거로 안 돌아감)

### 3-3. 변환 후 띄어쓰기 유지 OFF
- [ ] 설정에서 "변환 후 띄어쓰기 유지" **끄기** (되돌리기는 다시 ON)
- [ ] `ㅎㅌ` + 스페이스 → **`♥`** (뒤에 공백 없음)
- [ ] `안녕` + `ㅎㅌ` + 스페이스 → `안녕♥` → 백스페이스 1회 → **`안녕ㅎㅌ`**
      *(공백을 안 넣었으므로 한 글자 덜 지워야 함 — `안녕` 이 깨지면 버그)*
- [ ] `ㄱㅅ` + `.` → **`감사합니다.`** (기호는 이 설정과 무관하게 유지)
- [ ] 확인 후 설정 원복 (띄어쓰기 유지 ON)

---

## 4. 후보 선택 모드

- [ ] `ㅈㅅ` + 스페이스 → 후보 바에 `죄송합니다` 표시, 화면 텍스트는 `ㅈㅅ ` 유지
- [ ] 후보 탭 → `죄송합니다 `
- [ ] 후보 바 무시하고 계속 타이핑 → 후보 바 사라지고 원래 글자 유지
- [ ] `ㅈㅅ` + `.` 로 띄운 후보를 탭 → 결과 뒤에 **마침표**가 붙어야 함 (공백 아님)

---

## 5. 등록 화면 검증

- [ ] 트리거 제한 **안전**에서 `ㅋ` 1글자 입력 → 저장 버튼 비활성 + **빨간 사유 문구** 표시
- [ ] 안전에서 `.ㄱ` 입력 → 차단 (기호 뺀 실질 글자가 1자)
- [ ] 안전에서 `.ㄱㅅ` 입력 → 저장 가능
- [ ] 트리거에 **띄어쓰기** 포함 (`ㅋ ㅋ`) → 두 정책 모두 차단 + 사유 표시
- [ ] 트리거 제한 **자유**로 변경 → `ㅋ` 저장 가능
- [ ] 자유로 저장한 1글자 단축어를 두고 정책을 **안전**으로 되돌림
      → 목록에 그대로 남아 있고 **키보드에서 계속 동작**해야 함 (소급 적용 없음)

---

## 6. 상호작용 / 상태

- [ ] **더블 스페이스 → 마침표**: `ㅎㅌ` + 스페이스(`♥ `) + 스페이스
      → `♥. ` 이 되면 **버그**. `♥  ` (공백 2개)가 정상
- [ ] **커서 이동 후**: `ㅎ` 입력 → 스페이스바 드래그로 커서 이동 → `ㅌ` + 스페이스
      → 변환 없어야 함 (버퍼 리셋)
- [ ] **커서 탭**: 텍스트 중간을 탭해 커서 옮긴 뒤 `ㅎㅌ` + 스페이스 → 그 자리에서 정상 변환,
      중복 삽입 없음
- [ ] **한/영 전환**: `ㅎ` 입력 → 한/영 → 다시 한글 → `ㅌ` + 스페이스 → 변환 없음
- [ ] **앱 전환**: 설정에서 토글 변경 → 다른 앱으로 전환 → 키보드 다시 올림
      → 변경한 설정이 즉시 반영
- [ ] **단축어 사용 OFF**: 마스터 토글을 끄면 어떤 트리거도 발동하지 않음, 다시 켜면 즉시 동작

---

## 7. 실패 기록 양식

문제가 나오면 아래를 그대로 적어 주세요. 재현에 필요한 정보가 전부 들어갑니다.

```
호스트:            (예: 카카오톡 대화 입력창)
설정 상태:         띄어쓰기 유지 ON / 되돌리기 ON / 트리거 제한 안전
등록된 트리거:     .ㅎㅌ → ♥♥
입력 순서:         안녕 → . → ㅎ → ㅌ → 스페이스
기대한 결과:       안녕♥♥
실제 결과:         녕♥♥          ← 앞 글자가 먹힘
재현율:            5회 중 5회
```

가능하면 화면 녹화도 함께 남겨 주세요 — 조합 중 글자가 순간적으로 깜빡이는 문제는
스크린샷으로는 안 보입니다.
