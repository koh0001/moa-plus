# 순정 모아키 관찰 영상 판독 결과 (2026-08-13)

`moakey_screen_recording/` 47편(기본 40 + 재촬영 R1~R7. 갤럭시 + 삼성 모아키,
포인터 위치 오버레이 ON)을 프레임 단위로 판독해 순정 입력 규칙을 확정한 기록.
촬영 가이드는 [MOAKEY_RECORDING_GUIDE.md](MOAKEY_RECORDING_GUIDE.md), 남은 촬영
목록은 [MOAKEY_RESHOOT_LIST.md](MOAKEY_RESHOOT_LIST.md), 실기기 확인 체크리스트는
[V2_DEVICE_TEST_CHECKLIST.md](V2_DEVICE_TEST_CHECKLIST.md).

판독 방법: 6fps 몽타주로 시도 시점 파악 → 풀해상도 크롭(궤적/텍스트/dX·dY 수치 바)
→ 시도별 (시작 키, 획 시퀀스·각도, 결과 글자) 재구성. 일부 그룹은 십자선
배경차분·OCR 로 좌표 시계열까지 복원했고, **키 위 실시간 미리보기 팝업의 글자
변화**(예: 고→괴→과→괘)를 트라이 구조의 결정적 증거로 썼다.

## A. 확정된 규칙 → 구현 반영됨 (v1.8.x)

### A-1. 획 판정 모델
- **단일 획의 방향 = 터치다운→업 순 변위(net) 벡터 하나** (F 섹션 40/40 예외 없음).
  획 중간 곡률·손 뗄 때 순간 방향은 판정에 안 들어간다. 섹터는 정확히 45° 등분
  (67.5°/112.5° 경계 실측).
- **꼬리는 "트림"되는 게 아니라 레버리지가 없다**: 길이 L 획 끝의 T 꼬리는 net
  각도를 atan(T/L)만 움직인다. 경계 몇 도 이내의 획이 아니면 모음을 못 바꾼다.
- **최소 획 길이 문턱 (40, 70]px** (1080px 폭 기준, 키 폭 154px): 그 아래는 탭.
  OS 터치 슬롭(~22px)의 약 3배인 **별도 IME 문턱**이다.
- **획 분리 = 방향 전환(turn) 감지**: 전환 55° 이하는 한 획으로 흡수(대각선
  단모음), 60° 이상은 새 획 (D 섹션). 되돌림이 획으로 인정되는 크기는
  (25, 135]px 사이 (F2 #2: 70px↑ 후 135px↓ = ㅚ — **순정도 이 오타는 난다**).
- **속도 무관**: "too fast" 거부 없음. 획이 들어올 때마다 즉시 재판정(미리보기
  점진 승격 ㅜ→ㅟ→ㅠ), 손 뗀 시점 상태로 확정 (E 섹션). 왕복 이격 ≈0, 원점
  복귀 불필요, 복귀 획 오버슈트 최대 170px 전부 정상 인식 (A 섹션).
- **트라이 끝 도달 후 획은 조용히 무시** = 유효 최장 접두사 (614px 획도 버림).
  실패해도 항상 "다른 완성 모음"이 나오지 눈에 안 보이는 무효는 없다.

### A-2. 첫 획 8방향 잠정 → 후속 획 도착 시 4방향 재해석 ★
- 단독 ↗↖=ㅣ, ↙↘=ㅡ (B 섹션 17회 예외 없음, 35~58° 구간).
- **후속 획이 등록되면 첫 대각선 획을 실제 각도 기준 카디널로 재해석한 해석이
  함께 성립**한다 (A8-A13 §3):
  - ↗(≤45°) 나갔다 ↙ 복귀 = **ㅐ** (C 섹션 4/4, 팝업 ㅣ→ㅐ. 리뷰 "ㅐ 방향이
    순정과 다름" 지적의 원인이었다), ↗ 후 ← = ㅐ, ↗ 후 ←→← = ㅒ
  - ↖ 후 ↘ = **ㅔ** (A8 #6; ← 후 ↖/↑ = ㅔ 로 F 섹션 상호 확인)
  - ↙(수직 쪽) ↑↓ = **ㅠ**, ↙(수평 쪽) →← = **ㅕ** (A9/A11)
  - 단, **↙↗ / ↘↖ 반전은 천지인 ㅡ+ㅣ = ㅢ 가 우선** (B3 4/4, E3 — ㅢ의
    실제 입력 경로가 이것이다. ㅣ키 탭이 아님)
- 구현: `GestureAnalyzer.finalizeGestureDetailed()`가 첫 획 벡터의 4방향 스냅을
  넘기고, `VowelResolver`가 원 해석과 재해석을 모두 트라이에 넣어 **더 많은
  간선을 따라간 쪽** 채택 (동률 = 기존 해석 → ㅢ 보존).
  `MoakeyVideoVerifiedSpecTests` 가드.

### A-3. 트라이 확장 (팝업 체인으로 확정)
- 세로 체인: **↑↓→ = ㅘ, ↑↓→← = ㅙ, ↑↓↑↓ = ㅠ** (ㅗ→ㅚ→ㅛ→ㅠ, 고→괴→과→괘).
  ↓↑↓↑ 는 ㅠ 유지(4획째 무시).
- 자음 키에서도 **ㅒ=→←→←, ㅖ=←→←→** 4획 성립 (기존 코드와 일치 —
  CLAUDE.md 의 "ㅣ키 전용" 기재가 틀렸던 것).
- 나머지 12개 조합(ㅘ ㅝ ㅚ ㅟ ㅐ ㅔ ㅛ ㅠ ㅑ ㅕ ㅙ ㅞ)은 기존 스펙과 일치 확인.

### A-4. 조합 상태머신 (G·H 섹션)
- 완성(받침무)+자음 = 받침 결합 (8/8, ㅋ 포함). 받침+모음 = 이월. 완성+모음 =
  같은 음절 중성 합성 (가→갸→걔). 합성 불가 모음은 별개 클러스터. — 기존 구현과 일치.
- 겹받침: 표준 조합만 (ㅄ ✓, ㄱㅂ/ㄱㄱ ✗). 이미 겹받침이면 새 음절. — 기존 구현과 일치.
- **ㅛ+ㆍ=ㅗ, ㅠ+ㆍ=ㅜ 무한 토글** (H2) → `combineVowels` 에 추가.
- **백스페이스 = 자소 단위** (G5): 받침→중성(통째, ㅐ→ㅏ 안 됨)→초성.
  받침 없는 완성 글자에서 **초성을 남긴다** (가→ㄱ) → `deleteBackward` 수정.
- ㆍ 누적 중간 표시: 순정은 조합 중 음절 오른쪽 별도 칸에 ㆍ/ᆢ 렌더 (한 조합이
  두 칸에 걸침). 우리는 marked text 미지원 제약으로 단일 칸 표시 유지 — 최종
  결과는 동일.

## B. 관찰됐지만 반영하지 않은 것 (근거)

- **후속 획 허용대가 첫 획보다 ~60° 넓음** (D): 우리 window 분류가 이미 상당
  부분 흡수. 수치 이식은 좌표계가 달라 불가 — 문제 재현 시 참조.
- **후속 획 길이 비율 밴드** (<0.65 실패 / 0.65~0.85 혼재 / ≥1.0 안정, D):
  혼재 구간이 실재해 단일 임계 이식 금지.
- **순정 미리보기가 첫 획 도중엔 자음만, 2획부터 모음 표시** (A10): 우리는 첫
  획부터 표시 — 사용성 차이일 뿐 오타와 무관.
- **`consonantDiagonalDerivationEnabled`**: 반전 획(↙↗=ㅢ)은 순정에도 있음이
  확인됐지만 그건 트라이가 이미 처리한다. 이 설정의 나머지(대각선+카디널 파생
  ㅗ/ㅜ/ㅘ…)는 순정 미확인 + v1.7 오타 원인이므로 **기본 OFF 유지**.

## C. 재촬영(R1~R7) 판독 결과 — 2026-08-13 오후

- **R1 (ㅝ↔ㅟ)**: 1차의 "얕은 각 ←=ㅟ" 관측 2건은 **기각**(좌표 바 없던 시절
  오독). 얕은 2획(±24°)은 8/8 ㅝ, 위로 ~26°±2° 넘으면 ㅟ, 아래로 처지면 획
  미등록 → 전체 ㅡ. 순정은 획 진행 중 연속 판정 + "← 섹터를 스치면 ㅝ 래치".
  우리 구조와 정합(22.5° vs ~26.5°는 튜닝 범위) — 변경 없음.
- **R2 (→ 후 직각)**: →↓/→↑ = **ㅐ** (6/6), →↓→=ㅑ, →↑→←=ㅒ. 수평 시작
  트라이엔 직각 간선이 없어 반전으로 스냅 → `normalizeTrailingStroke` 반영
  (수평 시작 제스처 한정 — 수직 시작은 D4 실측대로 무효 획 폐기 유지).
- **R3 (겹받침+모음)**: 값+모음 = 갑+새 음절 (뒤쪽 자음만 이월, 3/3) — 우리
  구현과 완전 일치, 변경 없음. 순정은 dotPending 중 분리를 모음 확정까지
  미루는 표시 차이만 있음.
- **R4 (섹터 경계)**: 45° 등분(22.5/67.5)이 5개 경계 전부와 정합 (↙/↓ 는
  (63.4°, 69.2°)로 최타이트). 변경 없음.
- **R5 (되돌림 임계)**: 되돌림이 2획으로 인정되는 최소 크기 **(45, 51)px =
  키 폭의 29~33%** (6/6 단조). 우리 reversal 임계(~20%)보다 순정이 엄격 —
  실기기 튜닝 후보 (체크리스트 T-1). 절대 vs 비율(0.4) 임계는 판별 불가.
- **R6 (ㅒ 정지)**: **획간 타임아웃 없음** (393ms 정지 성공 / 53ms 정지 실패,
  동일 프로파일에서 성패 갈림). 순정의 →←→← ㅒ 는 자체적으로 비결정적(8회 중
  3승) — C3 #4 는 재현할 버그가 아님. 변경 없음.
- **R7 (↑↓←→)**: **ㅖ 5/5 재현** (A12 #8 은 오판독 아님). 팝업 오→외→여→예.
  신규 간선 4개 반영: ↑↓←=ㅕ, ↑↓←→=ㅖ, ↓↑←=ㅝ, ↓↑←→=ㅞ. ㅚ 꼬리
  회귀 가드(`testE2E_upDownWithSmallLeftTail_staysOe`) 선행 추가.
